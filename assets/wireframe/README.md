# Wireframe and Figma handoff

- [`pocket-7-screen-board.svg`](pocket-7-screen-board.svg) is a vector board with seven core screen concepts and a visual route map. Import it into Figma, ungroup the SVG, and put each phone concept in its own 390 × 844 Android frame.
- [`../../docs/06-figma-handoff.md`](../../docs/06-figma-handoff.md) lists the prototype hotspots and the behavior expected at each connection.
- [`../../docs/05-style-guide.md`](../../docs/05-style-guide.md) defines colors, type, spacing, radii, and component states.

The SVG is an editable starting board; it is not a published Figma file or a clickable prototype. Add Figma prototype connections after import using the handoff map.
